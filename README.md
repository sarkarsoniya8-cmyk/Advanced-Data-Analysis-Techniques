# Advanced Data Analysis Techniques: Natural Language Processing (NLP)

Sentiment classification of customer reviews using TF-IDF features and supervised models, with a generated project report.

## Technique and application
**NLP with TF-IDF (unigrams and bigrams) and supervised text classification.** Companies receive thousands of reviews and support messages. Automatic sentiment analysis flags unhappy customers early and shows which phrases signal dissatisfaction.

## Data
| Mode | When it is used | Data |
|---|---|---|
| Real data (default) | `USE_REAL_DATA = True` and internet access (works in Colab) | IMDB movie reviews (HuggingFace `datasets`), a balanced sample of 6,000 reviews labelled Positive or Negative |
| Fallback | the download is not possible, or `USE_REAL_DATA = False` | `data/customer_reviews_nlp.csv`: 1,200 **synthetic** telecom-style reviews built from a small set of template sentences (only 176 unique texts) |

The report states which dataset was used. Results on the synthetic file are near-perfect because the text is simple and repetitive; that is not evidence of a strong model, so real data is the meaningful evaluation.

## Workflow
1. Load the data, check quality and **remove duplicate texts before splitting** (so no review is in both training and test)
2. Clean the text (lowercase, remove HTML and punctuation)
3. Stratified 80/20 split
4. TF-IDF **inside a pipeline** (fitted on training text only, which prevents leakage)
5. Compare Multinomial Naive Bayes, Logistic Regression and Random Forest with 5-fold cross-validation, then evaluate once on the test set
6. Confusion matrix, error analysis and top phrases per class
7. Generate `reports/advanced_analysis_report.md` from the run

## How to run
```bash
pip install -r requirements.txt
jupyter notebook notebooks/nlp_sentiment_analysis.ipynb     # Run > Run All
```
In Google Colab: upload the notebook (or open it from GitHub) and choose **Runtime > Run all**. If you use the bundled CSV in Colab, set `GITHUB_REPO` in the loading cell or upload the file when asked. After the run, download the new `reports/` and `images/` files and commit them.
